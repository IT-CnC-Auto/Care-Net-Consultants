## How to use this list

1. Open any page with `?design=1` at the end of the address (or `#design`). Every asset slot is outlined and numbered, and a panel lists each asset's full specification with a button that copies it as JSON.
2. The numbers in this list match the numbers on the page.
3. Supply every format listed for an asset, at the pixel size shown, and keep each file at or under its maximum size.
4. Name each file exactly as shown under File name and deliver it to the path under Delivery.
5. Alt text is written by Care Net. It is listed so the picture matches the words that describe it.
6. Status Needed means the asset does not exist yet. Existing means it is live and is listed for reference.
